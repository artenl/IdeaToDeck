# IsThisIdeaGood

Type in any idea. A small LangGraph pipeline of specialist agents then:

1. searches the web to see whether the idea already exists,
2. works out how comparable businesses make money,
3. scores the idea against a fixed rubric, citing evidence,
4. explains how you could execute it.

It's built to cost about a cent per run and to run on a single small VPS.

Status: planning. See [PLAN.md](PLAN.md) for the architecture, cost model, hosting setup and milestones.
